# Avengers Limited Edition switch matrix

Source: `Avengers-LE-Manual-compressed.pdf`, PDF page 63, printed page 4.

The page is the complete `SWITCH MATRIX GRID [#1 - #64]`, followed by the dedicated D-1 through D-32 switch block and CPU/sound-board DIP positions. It visibly records the Limited Edition matrix wiring and physical labels for the trough, shooter lane, gates, ramps, Tesseract optos, Hulk targets, Loki lock, Hulk plate, eject, and orbit switches.
