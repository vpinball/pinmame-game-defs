# Flash Gordon - Parts list coils and modules, and the manual's own date

Transcribed from `Flash Gordon Bally 1981 English Manual.pdf`, PDF page 25, printed page 20, headed
`XI. PARTS LIST / #1215 FLASH GORDON`, plus the copyright line on the cover, PDF page 1. This page is
single-column running text that the retained PDF's text layer reproduces cleanly; it was still
checked against a 200 dpi render.

| Single Drop Target Reset | - | AO-27-1300 |
| Saucer Kickup | - | AO-27-1300 |
| Saucer Kickdown | - | AO-29-2100 |

Eleven coil entries. An entry with no printed quantity is a single coil, so the page totals sixteen
coils: three flippers, three thumper-bumpers, two slingshots, three drop-target reset coils, and one
each of coin lockout, knocker, outhole kicker, single drop target pulldown, single drop target reset,
saucer kickup and saucer kickdown. **`Flipper (3)` is the machine's flipper-coil count**, and the
three Drop Target Reset coils are the 4-bank, the 3-bank and the in-line bank sharing one part
number.
