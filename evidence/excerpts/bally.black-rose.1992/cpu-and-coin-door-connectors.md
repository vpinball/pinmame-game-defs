# Black Rose — CPU Board A-12742-20013 and Coin Door Interface Board A-14689 Connector Lists

Transcribed from `Bally_1992_Black_Rose_Manual.pdf`, PDF pages 120 and 124, printed pages `BLACK ROSE 3-16` and
`BLACK ROSE 3-20` (footers read on each page), the `CPU BOARD A-12742-20013` and `COIN DOOR INTERFACE BOARD A-14689`
connector lists. Read from the rendered pages (300 dpi image-only scan), not from the OCR text.

Each row is one printed line, in printed order, split into the connector-pin designator (column 1) and the rest of the
printed line (column 2); a line printed without a pin number (for example `J203 Not Used`) has the bare connector
designator in column 1. Blank lines between connector groups are not shown. Spelling, capitalization and punctuation are
as printed, including these oddities: `J205-4 ... 4th Coin J1-17` has no `to`; `J1-10 Orange- Blue` has a space after the
hyphen; `J3-11 Orange-Grey` and `J205-9 Orange-Gray` use two spellings of grey; the coin-door lists on page 124 print
`Green-Brown, switch column 1` on both `J6-7` and `J6-8`. Each page also prints a board layout drawing (top right of
page 120, top of page 124) whose connector outlines carry the connector names; the drawings are not transcribed. Each page
prints the `P.C. Board Legend` box, transcribed once at the end. No cell is illegible.
