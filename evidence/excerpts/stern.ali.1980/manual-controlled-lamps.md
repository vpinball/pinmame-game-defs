# Ali controlled-lamp chart (technical chart)

The retained Stern Ali technical chart lists the controlled-lamp SCR number, connector, lamp description, wire color, and transistor type for the discrete lamp outputs. It also shows the unnamed fitted SCR positions, which the definition preserves as unused outputs rather than silently dropping. This chart is discrete controlled-lamp evidence, not a row-and-column lamp matrix.
