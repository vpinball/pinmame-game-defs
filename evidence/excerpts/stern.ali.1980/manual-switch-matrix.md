# Ali switch matrix (technical chart)

The retained Stern Ali technical chart prints the complete five-strobe by eight-return switch matrix, including the coin and credit controls, thumpers, slingshots, drop targets, saucers, lanes, outhole, outlanes, return lanes, and unused positions. This is the physical matrix and printed-address evidence; the known-working VPX script remains ground truth where its runtime semantics intentionally differ from a chart label.
