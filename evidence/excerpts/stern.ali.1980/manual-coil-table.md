# Ali coil table and flipper circuits (technical chart)

The retained Stern Ali technical chart lists the nineteen service solenoid positions, their descriptions, momentary or continuous behavior, connector, driver transistor, and coil type. It also prints the two flipper circuits, including the power wire, flipper-coil wire, button wire, and J-25-450/34-4500 coil assembly. The deterministic definition reconciles the chart's physical/service numbering with PinMAME's public output addresses using the ROM service sweep.
