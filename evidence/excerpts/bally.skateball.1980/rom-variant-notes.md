# Skateball — retained free-play set notes

Source: user-authorized `skatebla.zip`, archive SHA-256 recorded in `evidence/runtime/by35/skateball-1980-solenoid-tests.json`, member `info.txt`. Primary curator read the original member; line endings and spacing normalized in this compact factual transcription. No ROM bytes are reproduced.

The archive identifies version 1, date 031004, change “add free play”, recalculated checksum, and installation on2732 EPROM. For SKATEBALL it pairs SKAT2732.U2 with720-4032.U6. With DIP25 and 26 both ON, free play prevents credits decreasing below 01. The note is signed Oliver. The archive carries U6 file `7406fn.u6`, CRC32 `43a5f459`, the same bytes the pinned PinMAME driver identifies. The other games named in this multi-game note are not evidence for Skateball's playfield.

The later `skateblb` archive contains `skate02.u2`, `skate02.u6` and the same `823-02_4.716` sound ROM, with no instruction text. Its title, firmware year2005 and revision3/improved-attract description come from pinned PinMAME. No extra option meaning is inferred for that set. The independent service runs show the same13 public coil/self-test pairs on all three ROMs, while PinMAME gives them the same generation, display, sound-board and flipper declarations.
