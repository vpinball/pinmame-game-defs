# Physical identity and changes

IPDB machine 3281 was read at its own page on 2026-10-21: SlugFest (First Model),
March 1991, Williams, model 60001, WPC Dot Matrix, two players. The page identifies
blue upper-playfield Double inserts, white base squares, red instruction banner
under glass, red cabinet upper trim and original card dispenser A-14471.
It separately identifies 60021/5949 and 60121/6023. It does not establish the
third model's year or complete controller compatibility.

Williams Parts Catalog Supplement 16-9190-B selected-pages PDF 7/printed 11-1,
visually checked: manual 16-60001-101 for Slugfest 60001; manual 16-60021-101 for
Slugfest 2 60021. All parts and assemblies for 60021 are identical to 60001 except
the Card Dispenser Assembly (referenced 11-23a/11-23b). The same sheet lists
cabinet artwork separately for the two models. PDF 12/13/11-22/11-23 shows
original A-14471 (printed 11-22/11-23); PDF 14/15/11-23a/11-23b shows A-14471-1. Both retain gear
motor A-14469, low-card microswitch 5647-12693-01 and PCB A-14633. The revised
assembly changes magazine, pressure and lock parts and uses transmitter
A-17231/detector A-17232 in place of A-14315/A-14316. This is a distinct
mechanical option; the shared controller contract is not proof of identical
feed geometry, cam timing or failure behavior.

Amendments PDF 1/#1 (16-60001-AMD): initial defaults two cards per 50c or six
tickets per 50c; several pricing presets corrected. PDF 3–4/#2
(16-60001-AMD-2): correct card-chute carriage-bolt number 4320-01123-18,
ticket rate six per quarter, new factory default 25c/inning and $2/final nine
innings with one card/quarter. C.1 Set Cards, C.2 Set Tickets and C.3 Set Coin-Op
replace redemption/credit awards as specified. Ticket/Game Start and Ticket/Buy-in
become zero; four Ticket/Level Run settings become 2,4,6,8. Changes to pricing
may require proportional changes in ticket/run thresholds; do not freeze one
manual's defaults as universal firmware rules.

PDF 5/#3 (16-60001-AMD-3): screen A-14811 replaces A-14563 beginning at serial
730516. References manual 2-2,2-6 and 2-35; drawing changes the rear screen, not
controller I/O. PDF 7/#4 (16-60001-AMD-4): hinged door A-14940 replaces A-14612
for serial 731027+, references 2-2,2-4 and 2-35. Both are within first-model
production and do not justify a new ROM grouping.

The canonical record describes model 60001 with its original card dispenser.
Later models and optional ticket conversion remain explicitly bounded knowledge;
their additional geometry/behavior is not claimed as author-ready coverage.
