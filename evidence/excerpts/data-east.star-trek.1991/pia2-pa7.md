# Star Trek PA7 firmware behavior

PinMAME revision `46e1a01a0f73dc5ce163d98db1ae435883ecc450` maps the standard-order PIA2 to CPU addresses $2800–$2803 (`src/wpc/s11.c`, memory tables and PIA configuration). `pia2a_r` feeds port A from `core_getDip(0) << 7`. Bit 0 of the bank reaches PA7 because `src/machine/6821pia.c` stores the callback result in an 8-bit input latch. At $2800, CRA bit 2 selects the data register instead of DDRA. The data read combines each output latch bit selected by DDRA with the external input on the remaining bits. The write callback receives only the output bits selected by DDRA.

`src/wpc/degames.c` uses `input_ports_des11`, generated by `DE_INPUT_PORTS_START` in `src/wpc/s11.h`. Its common Data East input port has no Country option and declares no port after the cabinet switch port (index 2). `CORE_PORTS` in `src/wpc/core.h` defines the preceding ports and `SIM_PORTS` in `src/wpc/sim.h` extends the second one. At a new NVRAM initialization, `core_nvram` uses the low byte of `readinputport(CORE_COREINPORT+1)` for bank 0. The inport array is cleared by `src/inptport.c` before declared port bits are combined. The missing port gives zero. The two clean 2.01 switch-test runs independently observed default bank 0 = 0 at first harness poll. Saved NVRAM can carry a host value.

The seven distinct 64 KiB CPU images match PinMAME's member SHA-1s. The 1.10 Alpha Display set shares CPU 1.10. The 3.00 and 3.01 images were built from user-supplied 2.01 and the author's original IPS patches. CPU addresses equal image offsets for this ROM layout.

- The reset routine's PIA initialization sets CRA to $30, writes DDRA = $FF, then sets CRA to $34. Every PA pin is an output in this configuration, so external PA7 is masked.
- The main loop periodically dispatches through an eight-entry ROM pointer table. Entry 3, counting from zero, repeats CRA $30, DDRA $FF and CRA $34. This covers the separate PIA2 initialization through the indexed table rather than only the boot routine.
- The IRQ writes the display/strobe index masked to $0F, reads PA to acknowledge the PIA, and immediately overwrites A with the port-B control read. It makes no choice using the PA value.
- The fatal blink routine sets CRA $38, DDRA $10 and CRA $3C. It reads PA, exclusive-ORs bit 4 and writes PA. Only PA4 is configured as an output, so the external PA7 level cannot change the driven signal. A is reloaded before loop control.

Method: decode with the pinned 6808 opcode table, walk direct branches and calls from the hardware vectors, inspect both indexed calls reached by that walk, and scan every offset in [$4000,$FFF6) for extended operands $27FF/$2800/$2801 and immediate LDX bases $2700–$2803. The scan finds the two PA reads above, the boot, periodic and fatal writes, and no immediate indexed base in the PIA2 range. The RAM-backed scheduler call remains an indirect-flow boundary. The check supports the installed, grounded configuration and the reviewed CPU paths. It does not exhaust all computed indexed addresses or prove the effects of removing the strap on a real board.
