# Unofficial physical-machine firmware updates

PinballCode's release notes for Star Trek 3.00 (April 2020) and 3.01 (September 2026).

- Version 3.00 replaces the CPU and display ROMs on the Data East game. Among its changes are scanner awards, ball save, skill shot, and multiball progression.
- Version 3.01 replaces the CPU ROM while keeping the 3.00 display ROM. Both flipper buttons can request ball launch. The top gate stays closed during the re-light laser-kick behavior, and the top-left hole switches take over multiball jackpot recognition from the VUK switch. The new program also fixes a state that could stick GI on or off.
