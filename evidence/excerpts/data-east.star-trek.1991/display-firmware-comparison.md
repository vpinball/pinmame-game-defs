# Display hardware and firmware comparison

Data East Star Trek operations manual with schematics, retained IPDB PDF SHA-256 `14e13f5ab13e5b655c6251f2665b64458bcda485541f5956c17d4a88430fb45d`, visually checked against PDF pages 27, 36 and 47 (printed pages 23, 32 and 43).

- Backbox parts identification, printed p. 32, item 7: `Dot Matrix Display Bd`, part `520-5042-00`; item 8 is the display ribbon cable. The parts drawing shows the display in the backbox.
- Digital Display Test, printed p. 23: the intelligent dot-matrix board has a Z80A and game-specific personality ROM. The CPU ribbon sends data, reset and clock; the board returns status and busy. U13 and U14 drive columns and U15 drives rows. The automatic test lights dots, then columns, rows and alternating checkerboards, ending with `DOT MATRIX LIVES`.
- Combined Display Connections, printed p. 43, identifies display J1 ribbon lines as ground, busy, status, data 0–7, clock and reset. J2 carries power. The generic CPU logic drawing's alphanumeric connector legend is not a second display fitted by this game.

Pinned PinMAME `46e1a01a0f73dc5ce163d98db1ae435883ecc450`, `src/wpc/degames.c:549–633`, selects `GEN_DEDMD16`, `de_128x16DMD` and `de_mDEDMD16S2A` for all eight drivers. `src/wpc/dedmd.c:371–595` models the 520-5042-00 board's Z80, banked ROM, incoming command/busy handshake, status, row data/clock, dot shift/latch and blanking. This is emulator hardware evidence, not a physical bench measurement.

The authorized `trek_11a.zip` and `trek_110.zip` both contain CPU `trekcpu.110` (SHA-1 `989d70e067cd322351768550549a4e2c8923132c`) and the same sound images. They differ in the 128 KiB display ROM: `trekadsp.bin` SHA-1 `4251fa0568d2e869b44358471a3d4a4e88443954` identifies `DISPLAY: STARTREK A0.27`, with an internal 1991-10-23 build timestamp; `trekdsp.106` SHA-1 `3262d6604d1dcd1dc738bc3f919a3319b783fd73` identifies A1.06, timestamp 1991-11-19. Both contain `DOTMATRIXLIVES!!!`. `trekdspa.109` SHA-1 `d26126310b8b316ca161d4202645de8fb6359822` identifies A1.09, timestamp 1991-12-05. The A prefix appears on all three; it is not evidence of alphanumeric display hardware. PinMAME's label `Alpha Display` first appeared in commit `5f17214d8cac63a6b21493dd0a6deac1daf60e37` with the DMD16 ROM macro and does not document acquisition or physical installation.

The pinned combinations pair CPU 1.10 and 1.20 with display 1.06, and CPU 1.17, 2.00 and 2.01 with display 1.09. These are PinMAME combinations, not a statement that every pair was factory recommended. Service Bulletin 31, 1991-12-06, says game 1.17 and display 1.09 should be used as a pair; it describes launch, tech alert and display synchronization fixes and a restart-game adjustment. Bulletin 35, 1992-04-16, supplies CPU 2.00 and display 1.09, describing display timeout/reset and ball-search and relay changes. Both retained scans were visually checked.

The author's original unofficial fan patch archives `patch-300.zip` (SHA-256 `22fbb1c825f5e132b0b114b027f52f2cec3279967119d7a42031ea91147de745`) and `patch-301.zip` (SHA-256 `4c7b5f10cd536aa7406b1d6764a3c897d2c79a3eefad5c625b297a8b15225a65`) contain dated readmes and IPS patches. Both use the 2.01 CPU and 1.09 display as inputs; both replace ROMs on the physical game, and 3.01 retains the 3.00 display. Applying the retained patches in memory reproduces the pinned 3.00 and 3.01 CPU SHA-1s `a453208a7640a39cb96947e8d3d3b2f71f85e613` and `f8dd222b5237cf4bd8bc00f32980d68d339032f9`, and shared display SHA-1 `eebcc697b89bbe62b0450fdec6226a8396308f37`. Their original archives and derived ROMs remain outside Git. The release notes describe rules and behavior changes; a later firmware date is not a new physical machine.

From separate empty state directories, the pinned LibPinMAME binary ran `trek_11a` and `trek_110` using `tools/harness-scenarios/data-east/trek-display-boot.json`. Each produced 128 × 16 DMD updates. Visually checked retained boot frames identify A0.27 and A1.06 respectively; later snapshots show graphical attract animation. Raw runs, snapshots, states and a manifest are retained externally in `review-artifacts/data-east-star-trek-1991/display-probe-20261120/`; `tools/trek_display_evidence.py` verifies the exact ROM archives, CPU equality, display strings, traces and frame digests. The ROMs successfully drive an emulator model of the game's documented display board. This is strong compatibility evidence, not a physical test or a claim about where or when A0.27 was installed.
