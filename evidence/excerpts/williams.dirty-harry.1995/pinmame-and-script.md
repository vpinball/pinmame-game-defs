# Runtime and platform extraction

Primary curator read the retained embedded v2.0 script, the pinned v2.20 corpus script as corroboration, wpc.vbs/core.vbs and PinMAME97aa922bf8e4b6970126192ec1ac1fb0305a4f62. Factual extraction; table code/ROM bytes are not redistributed.

- Embedded script header: Dirty Harry1995 Williams, recreation Knorr, v2.0. cGameName dh_lx2; LoadVPM WPC.VBS; UseSolenoids2, UseLamps1; HandleKeyboard0, HandleMechanics0. The exact local source/table hashes are in the seed.
- Init sets22 and24 to1; four-ball trough InitSw0,32,33,34,35,0,0,0 with BallRelease. Release1 pulses31 only when the stack starts full and releases one ball. This simplified31 pulse does not define the actual optical jam location.
- Safehouse uses sw73/coil26; HQHole collects into LeftPopper switch47, exits through sw47/coil14; WarehouseEntry collects into WarehousePopper switch46 and exits sw46/coil4; trapdoor collects into GunPopper switch45 and exits sw45/coil5.
- Callbacks:1release,2autoplunger,3gunlaunch,4warehouse,5gunpopper,7knocker,14HQ,15rampdiverter,16trapdoorhold,20gunmotor,26safehouse,27leftdiverter,28rightloopgate,35magnet. Callback8 is commented out. Lower right/left callbacks move the flippers; right routine also rotates RightFlipper1, a simplification of the independently ROM-driven upper flipper.
- Switches15,16,17,25,26,42,66,67,68,71 use held contact states;38,41,43,51 are PulseSw ramp events;standups18,27,28,54-58, slings61-62 and jets63-65 pulse their own numbers.
- Gun motor20 enables an angular timer; the script reverses at-98/-2degrees and asserts76 from-4degrees. Those angles and speed are table tuning. It writes77 equal to motor enable, compensating for its simplified mini-trough. Chamber44 is set by sw44; enabled gun launch mistakenly clears coin3, not44. Disabled launch clears44 and re-enables the trigger200ms later. This defect is recorded, not adopted.
- Lamps use Lights(address)=lNN assignments plus LampCallback UpdateMultipleLamps. The insert map is11-68,77-78,81-86;87/88 are cabinet lamps absent from this table's Light array. No matrix71-76 lamp is inferred from that absence: the manual positively says Not Used.
- UpdateMultipleLamps drives bulbred from47, bulbyellow from48, domesmall1 from84, domesmall from85 and Bankrobber from38. It additionally lights l84a from48, a glow/render artifact. Flasher callbacks17/18/19/21/22/23/24 drive multi-Light effects; Light count is not socket count.23/24 share GIWhite1, which is also a rendering helper.
- GI callbacks: public4 -> GIString1;1 -> GIString2;0 -> GIString3. The collections contain Lights and Flasher sprites. Only explicit show_bulb_mesh objects contribute provisional emitter placements. Step0 and7 are skipped by this old table, a brightness-rendering defect.
- dhGameData: GEN_WPCSECURITY, wpc_dispDMD, FLIP_SW(FLIP_L|FLIP_U)|FLIP_SOL(FLIP_L|FLIP_UR), no extra lamp/switch/custom-output counts. invSw indexes0..11 are00,00,00,ff,7f,00,00,00,00,00,00,00. Under wpc_sw2m this masks31-38 and41-47. It does not prove fitment of masked36/37.
- WPC_SWROWREAD dispatches to wpc_pic_r; commands16..1f read raw internal matrix1..10. WPC_FLIPPERS returns the complement of column11. core_setSw/core_getSw apply the per-address mask; no second inversion is permitted. core_updateSw synthesizes declared EOS111/113/115 after coil timing but preserves undeclared117. Buttons112/114/116/118 remain host inputs with keyboard handling off.
- core_getSol:1-28 standard;29-32 remap solenoids2 bits8-11;33-36 upper outputs;37-44 returnzero on this generation;45-48 lower outputs;49-50 sim_getSol;51+ no dh hook. Power callbacks33/45/47 aggregate their power/hold masks. wpc.c publishes WPC_GILAMPS bits5-7 at29-31 and zero at32 when no fastflip address is configured, as on dh. sim_getSol returns shooterRel only for49, zero otherwise.
- The unconditional WPC_GILAMPS mirror is the complete generic virtual meaning of29/30 (J111 GPIO bits5/6). It does not establish a physical coil or require a guessed game-specific function. The absence of a30 transition in these probes is not non-use evidence. The same source explicitly distinguishes the Fliptronic legacy GameOn mirror from a real pre-Fliptronic relay.
- wpc.vbs v3.56 writes lower buttons112/114 and staged buttons116/118; keys write coins1-4, service5-8, start13 and coin-door22. core.vbs resolves cSolURFlipper from PinMAME metadata. The library files are retained machine-neutrally with hashes, not silently assumed from a table key handler.
- All three drivers share init_dh, generation, flipper flags and DCS sound ROM set. LX-2 is parent; LF-2 is French firmware and DX-2 the LED Ghost Fix. These firmware variants do not create a new physical grouping. A sample playfield with the removed warehouse drop/gate is documented within this machine's history; no separate sample driver exists in the pinned tree.
