# Theatre of Magic — Coin Door Interface PCB G.I. pins

Transcribed from `Theatre_of_Magic_OPS.pdf`, PDF page 154, printed page 3-32, "Coin Door Interface
P.C.B. Assembly A-17051-1" connector list. The committed crop shows the J2 block (left column); the
J5-1 to J5-3 rows are in the right column of the same page and are transcribed here without a crop.
Verified against a native-resolution render of the page.

| Pin | Printed text |
| --- | --- |
| J2-1 | Black ground from J116-3 |
| J2-2 | Gray-Yellow +12VAC from J116-2 |
| J2-3 | White-Violet G.I. 6.8VAC from J119-1 |
| J2-4 | Key |
| J2-5 | Violet G.I. from J119-3 |
| J5-1 | Violet G.I. return to coin door |
| J5-2 | White-Violet G.I. 6.8VAC to coin door |
| J5-3 | Black ground to coin door |

`+12VAC` on J2-2 is transcribed as printed; the Power Driver Board list (printed 3-27) calls J116-2
"Gray-Yellow +12VDC to playfield".

Reading: the Power Driver Board's J119 passes a White-Violet 6.8VAC / Violet return pair through this
board to the coin door. Those are G.I. string 05's wire colours (J121-11 White-Violet 6.8VAC, J121-6
Violet Return), so the coin door lamps are read as riding on string 05. The list does not name the
string, so that link rests on the wire colours.
