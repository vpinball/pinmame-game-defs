# TRON Legacy Limited Edition lamp matrix

Source: Tron-Manual.pdf, PDF page 59, LE LAMP MATRIX GRID.

The LE lamp grid covers lamp addresses 1-80 with eight columns and ten returns. It names the Tron, Zuse, Flynn, disc, Recognizer, ramp, orbit, bumper, eject, start and cycle inserts and leaves the unassigned addresses blank.
