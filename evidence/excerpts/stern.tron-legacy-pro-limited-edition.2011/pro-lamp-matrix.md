# TRON Legacy Pro lamp matrix

Source: Tron-Manual.pdf, PDF page 53, PRO LAMP MATRIX GRID.

The Pro lamp grid covers lamp addresses 1-80 with ten return rows and eight column drives. It names the Tron, Zuse, Flynn, disc, Recognizer, ramp, orbit, bumper, eject, start and cycle inserts, while the remaining addresses are explicitly blank in the matrix.
