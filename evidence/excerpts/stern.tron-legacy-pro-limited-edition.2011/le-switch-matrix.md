# TRON Legacy Limited Edition switch matrix

Source: Tron-Manual.pdf, PDF page 55, LE SWITCH MATRIX GRID.

The LE matrix covers switches 1-64 across four drives and sixteen returns. It labels the LE trough, shooter, ramps, loops, disc, Recognizer, target bank, spinners, orbit and back-panel motor contacts, with dedicated D-1 through D-32 and the CPU/Sound DIP switches below.
