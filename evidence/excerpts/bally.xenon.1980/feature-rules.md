# Xenon feature facts

Source: factory manual PDF pages 7-8, printed 4/4A, GAME FEATURES; factual paraphrase of the complete feature blocks. These are game rules, not measurements of physical timing.

| Feature | Factory behavior |
| --- | --- |
| Exit Chamber | Tube travel ends at the side saucer; score/advance the lit Exit Value; eject toward the right sling. S21 controls special repetition, S22 value memory, S23 one/two advances, S24 the 50K/90K ceiling. |
| Top Saucer | S15/S16 select 5K/no advance, 10K/one advance, or 10K/two advances. Each entry advances the center X sequence. |
| Multiball | First three-X completion qualifies tube capture; next completion releases the captive ball for two-ball play. Later sequences qualify outlane specials, then award a special. S30 controls X-light memory. Draining during multiball returns to tube qualification. |
| Four Drop Targets | Lit top buttons request matching individual trips. Completing all four scores 10K and the current 2X/4X/25K/extra-ball/special award. S6 enables initial 2X, S7 bank tube advance, S8 special repetition. |
| XENON Bonus | Starts at 2K, advances to 58K, retains 20K/40K super-bonus milestones. Tilt forfeits bonus. |
| Spinner | 10 normally; 1000 when lit during multiball. |
| Thumper Bumpers | 100 each. |
| Lane arrows | S14 selects both lit or one alternating. |

The exact option rows, including the source's duplicated S23 block, are preserved in operator-options.md.
