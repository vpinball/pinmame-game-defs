## Runtime VPinMAME library

The retained table loads `LoadVPM "01550000", "DE.VBS", 3.26` (script line 171) and sets `.HandleMechanics = False`, `.HandleKeyboard = False`. The machine-neutral `de.vbs` retained under `review-artifacts/vpm-script-libs` (SHA-256 `8858b4509a600f77a8a5844f138ed1c71f19b023550660efd62e308588e84d04`, "Last Updated in VBS v3.61") defines GameOnSolenoid = 23; swBlack = -7; swGreen = -6; swTilt = 1; swBallRollTilt = 2; swStartButton = 3; swCoin1 = 4; swCoin2 = 5; swCoin3 = 6; swSlamTilt = 7; swLRFlip = 82; swLLFlip = 84; swURFlip = 86; swULFlip = 88 (lines 20-36). Its `vpmKeyDown`/`vpmKeyUp` (lines 66-114) set 84 and 82 from the left and right flipper keys, Start writes 3, Black writes -7 while held and Green toggles -6 (`.Switch(swGreen) = Not .Switch(swGreen)`), matching the toggling `des11` Green input. The generic BallRollTilt name at 2 is not this game's identity; the manual and ROM print 4th Coin there. `core.vbs` defines the lower flipper callbacks sLRFlipper = 46 and sLLFlipper = 48.
