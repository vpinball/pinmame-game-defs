Source: `Sega_1995_Mary_Shelley_s_Frankenstein_English_Manual_pages_67_93_which_are_the_schematics_OCR_searchable.pdf` (SHA-256 `e4eeb409e321ea1eb3f9d30120e488db8b638a6d3d69f3c66c2c9ca7919bf883`), PDF pages 8 and 9 (300 ppi scans of a two-page spread, yellow paper).

Conventions: each table's text is copied cell by cell. Wrapped lines inside a cell are joined with a single space. Spacing inside printed quotation marks (e.g. `" F "`) and double spaces are kept as printed. `[blank]` marks a blank cell. The dash placeholder in the Part No. column, printed as a dash-dot-dash-dot-dash pattern, is written `— - — - —`. Nothing else was normalized.

### Switch matrix wiring drawing

Eight columns of switches SW9-SW16 (first column), SW17-SW24, SW25-SW32, SW33-SW40, SW41-SW48, SW49-SW56, SW57-SW64 (seven drawn columns of eight; the first column SW1-SW8 is not drawn on the matrix, the cabinet switches being omitted). Each switch is drawn with a diode in series. Seven drive lines run from the top connector down to the seven switch columns (the first drawn column connects to the GRN-RED line, the last to GRN-GRY) and eight return lines run to the right-hand connector.

CN8 (labelled `CPU BOARD` with a brace; drives):

| Wire | Pin | Label |
|---|---|---|
| GRN - RED | 2 | SWITCH DRIVE 2 |
| GRN - ORG | 3 | SWITCH DRIVE 3 |
| GRN - YEL | 4 | SWITCH DRIVE 4 |
| GRN - BLK | 5 | SWITCH DRIVE 5 |
| GRN - BLU | 7 | SWITCH DRIVE 6 |
| GRN - VIO | 8 | SWITCH DRIVE 7 |
| GRN - GRY | 9 | SWITCH DRIVE 8 |

No SWITCH DRIVE 1 / GRN-BRN line is drawn on this sheet (the first drawn column is SW9-SW16 on drive 2). The wire `GRN - ORG` is printed with `ORG`, not `ORN`.

CN10 (returns):

| Wire | Pin | Label |
|---|---|---|
| WHT - BRN | 9 | SWITCH RETURN 1 |
| WHT - RED | 8 | SWITCH RETURN 2 |
| WHT - ORN | 7 | SWITCH RETURN 3 |
| WHT - YEL | 6 | SWITCH RETURN 4 |

| WHT - BLU | 3 | SWITCH RETURN 6 |
| WHT - VIO | 2 | SWITCH RETURN 7 |
| WHT - GRY | 1 | SWITCH RETURN 8 |

Switch labels in the drawing run SW9-SW16 down the first column, SW17-SW24 the second, and so on to SW57-SW64 in the seventh column.
