Source: `Sega_1995_Mary_Shelley_s_Frankenstein_English_Manual_pages_1_66_which_excludes_schematics_OCR_searchable.pdf` (SHA-256 `2f752c431e3b2a4718180e52340c5394f36b41833a150464f04d52d442be8764`). The LAMP MATRIX CHART is on PDF page 36 (printed page 32, "Game Diagnostics"); the numbered list "Lamp Matrix Location and Descriptions" is on PDF page 37 (printed page 33); lamp-test text is on PDF pages 36 and 38 (printed pages 32 and 34).

Conventions: cell text is as printed in the chart. Where a cell wraps over several lines the lines are joined with a single space; where a word is broken with a hyphen at a line end ("Franken-" / "stein Mil-" / "lions Mode"; "Sarcopha-" / "gus Upper Scoop"; "Out-" / "Lane") the break hyphen is shown as printed in the joined text only for "Left Out-Lane Alive Kick-Back" (printed "Left Out-" / "Lane Alive" / "Kick-Back"); for "Frankenstein Millions Mode" and "Sarcophagus Upper Scoop" the line-end hyphen is removed. The lamp-matrix chart prints no shaded or blank cells. The first twelve lamps are printed in the chart as single large letters (F R A N K E N S in column 1; T E I N in rows 1-4 of column 2); the number is printed in the lower right of each cell and is the cell's lamp number. Lamp number = ((column - 1) x 8) + row; Column and Row in the table below are taken from the chart position.

## Lamp test text (PDF pages 36 and 38)

> "Controlled lamps are configured in an 8 x 8 matrix of columns (lamp drives) and rows (lamp returns) with up to 64 lamps possible. The lamp tests include four parts, all lamps, lamp return (row), lamp drive (column), and discrete (individual) lamps. Row and column wire colors are indicated in the discrete lamp test using corresponding resistor color code numbers."

> "Lamp Returns (Row): From the ALL LAMPS test, depress the STEP push-button switch. The display indicates LAMP RETURNS, wire color and the LAMP RETURN driver transistor. All controlled lamps in row 1 should be lit. Operating the Game Start push-button switch cycles through each of the rows separately."

> "Lamp Drives (Column): From the LAMP RETURNS test, depress the STEP push-button switch. The display will indicate LAMP COLUMNS, wire color and the LAMP DRIVES driver transistor. All controlled lamps in column 1 should be lit. Operating the Game Start push-button switch, cycles through each of the columns separately."

> "Single Lamp: From the LAMP DRIVES test, depress the STEP push-button switch. The display will indicate the lamp name. The display indicates the row and column wire colors and the lamp matrix number. Lamp 01 should light. With the FORWARD/REVERSE push-button switch in the FORWARD (up) position, operating the Game Start push-button switch selects higher-numbered lamps; with it in the REVERSE (down) position, Game Start selects lower-numbered lamps."
