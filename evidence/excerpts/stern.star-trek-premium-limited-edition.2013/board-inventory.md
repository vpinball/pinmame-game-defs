# Star Trek Premium / LE — board inventory excerpt

Source: `Star-Trek-LE-Manual.pdf`, PDF page 114, crop box 0.05,0.06,0.95,0.92. The crop transcribes the printed board inventory table listing game names, CPU board numbers, I/O power-driver board numbers, and U9 Pinball Boot ROM versions.

The inventory lists Star Trek and Star Trek L/E as using CPU board 520-5352-00; Star Trek uses I/O power-driver board 520-5249-00 (REV. D) and U9 boot ROM V1.0 (64M), while Star Trek L/E uses I/O power-driver board 520-5317-00 and U9 boot ROM V1.0 (64M). The table also identifies the neighboring Stern SAM games and board/ROM variants, providing the service-manual context for the Premium/LE electronics boundary.
