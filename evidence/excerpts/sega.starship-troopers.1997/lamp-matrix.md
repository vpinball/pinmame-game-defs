# Starship Troopers — Lamp Matrix Grid

Read from `Sega_1997_Starship_Troopers_Manual.pdf` (IPDB 4341), front-matter drawing `DR. 4` on PDF page 6, lower half
("LAMP MATRIX GRID"), from a 400 dpi render. The column drives are printed "Column (18v)" and the rows "Row (GND)". Lamp
number = (row − 1) × 8 + column. "DOTS" marks the vertical "Diode On Terminal Strip" tag printed in the cell. The cell
for lamp 33 is shaded and reads "NOT USED". Line breaks inside a printed name are joined with a space; a hyphen that
splits a word at a line end is kept as printed ("TUR-BO", "RE-TURN").
