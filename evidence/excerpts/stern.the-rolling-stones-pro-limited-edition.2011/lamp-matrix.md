# The Rolling Stones lamp matrix

Source: `Rolling-Stones-Manual.pdf`, PDF page 53, printed page 16.

The complete `LAMP MATRIX GRID [#1 - #80]` identifies the row and column wiring, lamp numbers, physical labels, LED/lamp type, and explicitly blank positions. It covers the start and shooter lamps, lanes, ramps, records, Mick positions, lock, pops, and top-lane inserts.
