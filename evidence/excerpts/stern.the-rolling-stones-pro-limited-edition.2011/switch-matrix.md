# The Rolling Stones switch matrix

Source: `Rolling-Stones-Manual.pdf`, PDF page 51, printed page 14.

The complete `SWITCH MATRIX GRID [#1 - #64]` lists the four drive columns, return wiring, matrix switch numbers, labels, and part numbers. The same page contains the dedicated D-1 through D-32 switch block and CPU/sound-board DIP positions; its note identifies switches 17, 50, D-7, D-13, and D-15 as Premium-model additions.
