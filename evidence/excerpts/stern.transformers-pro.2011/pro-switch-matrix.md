# Transformers Pro switch matrix

Source: Transformers-Manual.pdf, PDF page 129, PRO SWITCH MATRIX GRID.

The Pro supplement labels switches 1-64 across four drives and sixteen returns. It names the Bumblebee target, Energon, left/right ramps and orbits, Megatron locks, Optimus Prime, Starscream, Bumbler, and dedicated cabinet switches D-1 through D-32.
