# Transformers Pro lamp matrix

Source: Transformers-Manual.pdf, PDF page 133, PRO LAMP MATRIX GRID.

The Pro lamp grid covers addresses 1-80 with eight columns and ten returns. It names the start/tournament lamps, roll-out, Devastator, Blackout, Shockwave, Starscream, AllSpark, ramps, Energon, Megatron, Optimus Prime, Bumbler, Ironhide, lanes, bumpers and other playfield inserts.
