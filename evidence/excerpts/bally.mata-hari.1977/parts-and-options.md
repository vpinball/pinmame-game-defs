## Adjustments index

Normalized index to FO 579, printed pages 4/4A and 5/6/8
(PDF pages 8–11 and 13). The PDF's page 12 is blank. These are
physical DIP ordinals, independent of switch matrix numbers.

| S | Function |
| --- | --- |
| 1–5 | Coin chute #1 credits/coin |
| 6–7 | High game to date award: 0, 1, 2, or 3 credits |
| 8 | Melody: ON enables tunes |
| 9–13 | Coin chute #3 credits/coin |
| 14–15 | No assignment identified on the retained pages |
| 16 | Balls/game: ON 5, OFF 3 |
| 17–19 | Maximum credits: 5–40 in increments of 5 |
| 20 | Credits displayed: ON yes, OFF no |
| 21 | Match feature: ON enables match |
| 22 | No assignment identified on the retained pages |
| 23 | Saucer bonus multiplier: OFF conservative, ON liberal |
| 24 | A/B scoring: OFF conservative, ON liberal |
| 25–28 | Coin chute #2 credits/coin |
| 29 | No assignment identified on the retained pages |
| 30–31 | Replay, X-Ball or Novelty |
| 32 | High score feature: ON replay, OFF extra ball |

The centre chute's 4-bit table lists 1 through 15 credits per coin,
with all-off following chute #1. The outer chutes use 5-bit tables
with both one- and two-coin ratios. S23's conservative setting gives
no multiplier on the first visit and 2X/3X/5X on visits 2/3/4.
The liberal setting advances on visits 1/2/3. S24 gives a Special
on the seventh A/B completion in either setting, and additionally
on the ninth and eleventh on liberal. The special-mode chart
gives both switches on for replay, S30 off and S31 on for X-Ball,
and both off for Novelty.
