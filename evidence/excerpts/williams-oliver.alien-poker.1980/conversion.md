# Oliver Kaegi's Alien Poker multiball conversion

Candidate paraphrase of the retained `pro_alienmulti.html` hardware and software sections. The
author describes fitting a Firepower-style three-ball trough, moving the two right-flipper
assemblies and nearby parts, and connecting three trough contacts in series to the original
playfield-tilt switch wires so the input registers only when all three balls are present. The
existing outhole switch is replaced by the Firepower assembly's switch. The credit-knocker wire
is rerouted to the ball-ramp thrower; the former playfield-credit lamp circuit is reused for the
right eject-hole arrow. The page also describes enlarging the game ROMs and modifying game rules.
The production layout is therefore not interchangeable with this physical conversion.
