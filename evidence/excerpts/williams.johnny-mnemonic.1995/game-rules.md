# Williams Johnny Mnemonic (1995) — Game Rules (mechanism-relevant paragraphs)

Source: Williams *Johnny Mnemonic* operations manual (September 1995), IPDB machine 3683 file
`Williams_1995_Johnny_Mnemonic_English_Manual.pdf`, rules section, PDF pages 13-18 (unnumbered;
printed letter footers). Read from the native 300 dpi renders. Only the paragraphs that describe
mechanism or cabinet-button behaviour are transcribed; scoring-only paragraphs are omitted.

PDF page 13, `CYBERSPACE MATRIX SHOTS`:

> WHEN A BALL IS PLACED IN THE MATRIX, EACH HOLE GIVES YOU AN AWARD. THE AWARDS AND THEIR POSITIONS
> CHANGE. PUT THREE BALLS IN THE MATRIX TO START MULTIBALL.

PDF page 14, `SKILL SHOT:` (first sentences):

> Each time a ball is served for the player to launch, a SKILL SHOT is available in the top JET
> BUMPER entry lanes. A SKILL SHOT point value is awarded by using the flipper buttons to LANE CHANGE
> such that the ball rolls over the blinking light.

PDF page 14, `MNEMONIC RECOVERY:` (first sentence):

> This is a virtual kickback feature where the ball is returned to play by the AUTOFIRE mechanism.

PDF page 15, `ACCESS JET BUMPERS:`:

> The LEFT STANDUP TARGET opens the diverter which channels SPINNER and RIGHT LOOP shots into the JET
> BUMPERS for a timed period. This allows the player to control access to the JET BUMPER lanes.

PDF page 16, `VIDEO MODE:` (first two sentences):

> VIDEO MODE is a game played in the display using the four cabinet buttons. It is started by locking
> a ball in the VIDEO MODE position on the CYBERSPACE MATRIX.

PDF page 17, `CYBERSPACE MULTIBALL:` (first two sentences):

> CYBERSPACE MULTIBALL is a three ball multiball started by locking three balls in the CYBERSPACE
> MATRIX. The JACKPOT shots for this multiball are determined by the placement of the balls locked in
> the CYBERSPACE MATRIX, according to the red sign located on the right ramp.

PDF page 18, `POWERDOWN MULTIBALL (mode):` (second paragraph, first sentence):

> During POWERDOWN MULTIBALL, the game will continuously AUTOFIRE all of the balls in the game.
