# Williams Johnny Mnemonic (1995) — Lamp Matrix

Source: Williams *Johnny Mnemonic* operations manual (September 1995), IPDB machine 3683 file
`Williams_1995_Johnny_Mnemonic_English_Manual.pdf`, PDF page 100, printed page 2-32. Read from the
native 300 dpi render. The same grid is repeated on the unpaginated quick-reference sheet at PDF page
141.

A lamp symbol between the headers reads `Yellow (B+) ─(lamp)─►|─ Red`.

Column headers (column, wire, connector, driver): 1 `Yellow-Brown J137-1 Q98`; 2 `Yellow-Red J137-2
Q97`; 3 `Yellow-Orange J137-3 Q96`; 4 `Yellow-Black J137-4 Q95`; 5 `Yellow-Green J137-5 Q94`;
6 `Yellow-Blue J137-6 Q93`; 7 `Yellow-Violet J137-7 Q92`; 8 `Yellow-Gray J137-9 Q91`.

Row headers (row, wire, connector, driver): 1 `Red-Brown J133-1 Q90`; 2 `Red-Black J133-2 Q89`;
3 `Red-Orange J133-4 Q88`; 4 `Red-Yellow J133-5 Q87`; 5 `Red-Green J133-6 Q86`; 6 `Red-Blue J133-7 Q85`;
7 `Red-Violet J133-8 Q84`; 8 `Red-Gray J133-9 Q83`.

Note: the cyber-matrix lamp numbering runs the other way from the switch matrix. Lamp 51 is printed
`CYBER MATRIX 13` and lamp 71 `CYBER MATRIX 11`, while switch 51 is printed `CYBER MATRIX 11` and
switch 71 `CYBER MATRIX 13`. The labels, not the numbers, pair a lamp with its hole.
