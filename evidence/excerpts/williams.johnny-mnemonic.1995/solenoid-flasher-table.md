# Williams Johnny Mnemonic (1995) — Solenoid/Flasher Table

Source: Williams *Johnny Mnemonic* operations manual (September 1995), IPDB machine 3683 file
`Williams_1995_Johnny_Mnemonic_English_Manual.pdf`, PDF page 104, printed page 2-36. Read from the
native 300 dpi render. The same table is repeated on the unpaginated quick-reference sheet at PDF
page 2. This transcription covers the whole page; it is cited by two crops, `solenoid-flasher-table`
(rows 01-28) and `gi-and-flipper-circuits` (the General Illumination and Flipper Circuits blocks and
the footnotes).

Columns as printed: Sol. No. | Function | Solenoid Type | Voltage Connections (Playfield, Backbox,
Cabinet) | Drive Xistor | Voltage Connections (Playfield, Backbox, Cabinet) | Drive Wire Color |
Solenoid Part No. / Flashlamp Type (Playfield, Backbox). The second three-column group repeats the
header `Voltage Connections`; its J130/J127/J126/J122/J125/J124 cells are the drive connections, as
the flipper block's own `Drive Connections` header and the power driver board connector list
(printed 3-30) show, so the table below labels that group `Drive`. The G.I. rows sit under the same
repeated headers; there the connector list shows the first group holds each string's return and the
second its 6.8Vac feed. A dash marks a blank cell.

power/hold pair; `(same)` marks the repeated merged cell.

Footnotes, as printed:

- `J1XX = POWER DRIVER BOARD; J9XX = FLIPTRONIC II BOARD`
- `24-6549 = #44 BULB; 24-8704 = #89 BULB; 24-8768 = #555 BULB; 24-8802 = #906 BULB`
- `*THE X MOTOR AND Y MOTOR PART NUMBER IS 14-8025.`
- `** A-20532 IS THE PART NUMBER FOR THE DUAL RELAY MOTOR DRIVER BOARD.`

Note: the Left Diverter is printed on the Upper **Right** flipper circuit (33/34) and the Right
Diverter on the Upper **Left** circuit (35/36).
