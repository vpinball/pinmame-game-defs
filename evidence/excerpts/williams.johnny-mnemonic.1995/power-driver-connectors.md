# Williams Johnny Mnemonic (1995) — Power Driver Board Connector List (flasher, G.I. and lamp rows)

Source: Williams *Johnny Mnemonic* operations manual (September 1995), IPDB machine 3683 file
`Williams_1995_Johnny_Mnemonic_English_Manual.pdf`, PDF pages 137-139, printed pages 3-29 to 3-31
(`Power Driver Board Assembly` and `Power Driver Board Continued...`). Read from the native 300 dpi
renders. Only the connectors the definition relies on are transcribed; every line of each listed
connector is included; consecutive N/C pins are merged into one row here. Cited by `power-driver-connectors-3-29` (no crop),
`power-driver-connectors-3-30-left`, `power-driver-connectors-3-30-right`,
`power-driver-connectors-3-30-lamp-rows` and `power-driver-connectors-3-31`.
