# Last Action Hero (Data East 1993) - Game Specific Features

Transcribed by hand from a native-resolution (300 dpi) render of printed page 4 (PDF 8) of the IPDB scan `Data_East_1993_Last_Action_Hero_Manual.pdf`. The scan has no text layer, so the text below was read from the render. The page is footed `Game & Feature Specifications`. Its left column carries four numbered sections, transcribed below with their printed line breaks joined; its right column is a playfield outline on which section numbers are printed beside features, and it is not transcribed.

## GAME SPECIFIC FEATURES (printed page 4)

### 1) Skill Shot

The skill shot is available at the start of each ball. Pull the trigger on the gun to fire the ball into the CRANE drop targets. Hitting the lit CRANE target awards (1 + ball in play) million points. Hitting an unlit CRANE drop target awards (1 + ball in play) thousand points.

### 2) Crane Targets / Crane Lock

Completing the CRANE drop targets lights CRANE READY at the top right VUK and starts CRANE hurry-up. Shooting the crane before the hurry-up value reaches zero awards the value.
WARNING: hitting the DANGER bar behind the drop targets will reset the drop target bank. If difficulty adjustment 47 (Crane Hurry Up) is set to YES, in order to lock a ball in the TAR PIT, the CRANE shot must be made before the hurry up value reaches zero. If difficulty adjustment 47 (Crane Hurry Up) is set to NO, the CRANE shot can be made to lock a ball in the TAR PIT after the hurry up value reaches zero. Locked balls increase the jackpot values during M-BALL. A maximum of two balls can be locked in the tar pit.

### 3) Advancing to M-BALL

Shoot the captive balls (M-BALL Advance) to advance the M-BALL countdown to zero. Each captive ball shot decrements the count by 1. The left return lane switch (M-BALL advance x2) lights the right captive ball for a time period to score 2 captive ball hits, and the right return lane switch lights the left captive ball for a time period to score 2 captive ball hits. When the counter reaches 0, M-BALL is lit at tne left scoop.

### 4) M-BALL / Jackpot Qualification

Shoot the left scoop when lit to start M-BALL. Two balls will be put into play via the plunger lane, and any locked balls in the tar pit area will be released. If difficulty adjustment 46 (Crane Qualifies Jackpot) is set to YES, the ramp Jackpot must be qualified first by shooting the crane. If difficulty adjustment 46 (Crane Qualifies Jackpot) is set to NO, the ramp Jackpot will be available immediately at the start of M-BALL.

`tne` in section 3 is printed so. Section 4's heading is printed on two lines, `4) M-BALL / Jackpot` and `Qualification`.
