# Twilight Zone — Manual Amendment 16-50020-AMD-1, entries touching recorded devices

Transcribed from `Bally_1993_Twilight_Zone_Manual_Amendment_16_50020_AMD_1.pdf` (four pages, IPDB machine 2684),
PDF pages 2-4: the entries for manual pages 2-20, 2-25, 2-32/2-33, 2-47 and 2-51. Read from the 300 dpi renders; a
local OCR pass was used only to find the entries. The amendment's first page reads "The following
corrections/changes have been made to the Twilight Zone Operations Manual. Please keep this amendment with your
manual."

How the definition applies them:

- Switch 61 (Lower Skill): the manual's page 2-51 prints 5647-12693-32; the amendment supersedes it, and the record
  carries 5647-12693-57.
- Switch 74 (Gumball Popper): page 2-51 prints A-14231 (LED) / A-14232 (Trans), as does the Ball Popper Assembly
  A-16312 on page 2-25 (items 15 and 14; its coil AE-23-800 is solenoid 4's). The amendment changes those items to
  A-16908 (LED) and A-16909 (Photo Transistor); the record carries the amended parts. It has no page 2-51 entry for
  switch 74, and it changes no other opto on the switch list.
- Switch 57 (Slot Proximity): page 2-51 already prints A-16535; the amendment's page 2-47 entry names that part
  "Ramp Prox Opto sensor Assembly", which the record cites for the switch's construction.
- Page 2-20 item 2 is the flipper assembly's end-of-stroke switch. The definition records no part number for the
  end-of-stroke switches 111/113/115/117, so this entry changes nothing recorded.
- The clock assembly entry changes no socket item 24-29. No entry changes the Solenoid/Flasher Table (2-52), the clock
  test text (1-18), the Backbox Assembly (2-4), the Mini-Playfield Assembly (2-40/2-41), the switch matrix or
  mini-playfield switch drawing (2-50), or the power driver board connector list (3-33); the page 2-51 entry changes
  only switch 61, not switches 45 or 46.
