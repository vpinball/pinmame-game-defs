# Revenge From Mars community-code hardware milestones

Source: myPinballs Electronics, *Revenge From Mars - Code Updates*. Reviewed from the public update log at `https://www.mypinballs.com/software/rfm/code_updates.jsp`.

## Version 2.10

The update log states “System - Added shaker hardware control” and “System - Added knocker hardware control.” It separately lists adjustments for whether each device is installed. These are aftermarket devices rather than stock model 50070 fitment.

## Versions 2.22 through 2.50

Version 2.22 states “System - 6 ball trough now recognised once extra hardware installed.” Version 2.50 states that Capture Multiball “can use smart bombs to add 3 additional balls into play if trough is upgraded.”

## Version 2.60

Version 2.60 states: “This update and updates higher will require the full 4 opto pcb hardware expansion to operate correctly.” It also lists “Updates to the Right Lockup class to support physically locking 3 balls.” The retained v2.0 installation guide, not this log alone, identifies the four added inputs as two extra trough positions and two extra right-lock positions.
