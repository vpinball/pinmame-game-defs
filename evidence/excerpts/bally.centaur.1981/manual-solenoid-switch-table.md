# Centaur solenoid and switch identification table (factory manual)

The Bally Centaur manual's solenoid identification table names the eighteen self-test devices, including the outhole kicker, knocker, drop-target resets, thumper bumpers, slingshots, ORBS reset, ball release, kick to playfield, coin lockout, flipper-enable relay, and magnet. The same page identifies the numbered switch contacts and their physical descriptions, including the trough, lanes, targets, slingshots, bumpers, outlanes, and shared flipper button address. The printed self-test order is not assumed to be the PinMAME public output number; the definition reconciles it with the recorded ROM self-test.
