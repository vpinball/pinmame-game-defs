# Avengers Pro switch matrix

Source: `Avengers-Pro-Manual.pdf`, PDF page 13, printed page 11.

The page is the complete `SWITCH MATRIX GRID [#1 - #64]`, followed by the dedicated D-1 through D-32 switch block and the CPU/sound-board DIP switch positions. It visibly lists the matrix column and return wiring, switch numbers, names, and switch part numbers, including the four trough positions, shooter lane, orbit and ramp switches, Hulk targets, Tesseract optos, Loki lock, Hulk plate, eject, and target.
