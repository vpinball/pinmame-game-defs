# Avengers Pro lamp matrix

Source: `Avengers-Pro-Manual.pdf`, PDF page 19, printed page 17.

The complete `LAMP MATRIX GRID [#1 - #80]` identifies each matrix lamp position, row and column wiring, lamp type, and playfield label. The retained table includes the Thor, Hawkeye, Hulk, Black Widow, Iron Man, Captain America, Tesseract, ramp, lock, pop, orbit, and extra-ball positions, as well as explicitly blank addresses.
