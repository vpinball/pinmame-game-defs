# Lamp Matrix Grid (01-80)

Transcribed from `Stern_2006_Pirates_of_the_Caribbean_Pinball_Service_Game_Manual.pdf`,
PDF page 8, printed "DR. 6". Header reads
`LAMP MATRIX GRID (01-80) {Lamp Locations on the next page}`.

The printed grid is ten ground rows by eight drive columns. Lamp numbers run
**row-major**: row 01 carries LP. #1-#8, row 02 carries #9-#16, and so on to row 10 which
carries #73-#80. Rows 09 and 10 are the two auxiliary lamp rows.

The whole region is transcribed, including every bulb type and part number.

## Internal inconsistency preserved verbatim

LP. #77 (`LIARS DICE`) prints the bulb type `#555 Clear` but the part number
`165-5053-05-HF`, which is the `#44 Blue` part used by LP. #67, #68, #75 and #76 on this
same page. Both cells are transcribed as printed; this definition does not resolve which
of the two the machine actually carries because the fact is a bulb type, not an address.
