PDF page 6, printed "DR. 4" of the Find-It-In-Front / Dr. Pinball section. The page is
printed landscape. Header reads
`SWITCH MATRIX GRID (#1-#64) {Switch Locations on the next page}`.

The whole region is transcribed, including every `NOT USED` cell, so that an unclaimed
matrix position is visible without opening the manual.

## Notes on this page's own conventions

- Opto-constructed switches are marked by printing `(OPTO PAIR)`, `(VUK OPTO)` or
  `(STACK OPTO)` into the cell. This page carries **no** shaded-cell opto legend of the
  kind the Williams WPC-95 manuals used, and no cell on it is shaded for polarity.
- `« D.O.T.S. »` is defined on the following Lamp Locations page as
  `DOTS: Diode On Terminal Strip`. It is a wiring note, not an opto marker.
- `S/U` denotes a stand-up target; the colour and height (`YEL 1-1/2"`, `GRN 1/2"`) are the
  target face, not a construction type.
- The `Typical Switch Wiring Schematic` inset on the following page shows
  `Column: Switch Drive Wire (GRN-XXX)` -> blocking diode `1N4004` -> `Row: Switch Return
  Wire (WHT-XXX)`, with `N.O.`, `COM.` and `N.C.` terminals labelled
  `Normally Open Switch Terminal`, `Common Terminal`, `Normally Closed Switch Terminal`.
  It does not say which terminal any individual switch uses.
