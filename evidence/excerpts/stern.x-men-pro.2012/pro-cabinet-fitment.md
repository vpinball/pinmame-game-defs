# Pro cabinet button fitment

The manufacturer's Pro flyer PDF page1 contains a native1275x1650 JPEG at xref8. The native crop(420,1000,650,1380) shows a fitted green Start button and a black plug below it, with the coin door beside both. The lower opening has no tournament button in this photographed cabinet. The official Stern image `XMenPro-Right.png` depicts the same cabinet configuration.

The Pro matrix and firmware assign lamp1 START BUTTON, lamp2 TOURNAMENT START BUTTON, and switch15 TOURNAMENT START. These assignments establish supported functions, not universal button population. Lamp1 remains standard; lamp2 and switch15 are optional. Quantity1 on lamp2 means one emitter per fitted optional button. Stable device IDs and public bindings are unchanged. Both lamp functions remain cabinet spatially not-applicable.

The lamp inventory therefore has61 assigned functions, including optional2, and60 standard functions. It is not a claim that every Pro contains61physical lamps. All other blank/NOT USED lamp addresses retain their dispositions.
