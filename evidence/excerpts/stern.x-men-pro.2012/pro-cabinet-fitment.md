# Pro cabinet button fitment

The manufacturer's Pro flyer PDF page 1 contains a native 1275x1650 JPEG at xref 8. The native crop (420,1000,650,1380) shows a fitted green Start button and a black plug below it, with the coin door beside both. The lower opening has no tournament button in this photographed cabinet. The official Stern image `XMenPro-Right.png` depicts the same cabinet configuration.

The Pro matrix and firmware assign lamp 1 START BUTTON, lamp 2 TOURNAMENT START BUTTON, and switch 15 TOURNAMENT START. These assignments establish supported functions, not universal button population. Lamp 1 remains standard; lamp 2 and switch 15 are optional. Quantity 1 on lamp 2 means one emitter per fitted optional button. Stable device IDs and public bindings are unchanged. Both lamp functions remain cabinet spatially not-applicable.

The lamp inventory therefore has 61 assigned functions, including optional 2, and 60 standard functions. It is not a claim that every Pro contains 61 physical lamps. All other blank/NOT USED lamp addresses retain their dispositions.
