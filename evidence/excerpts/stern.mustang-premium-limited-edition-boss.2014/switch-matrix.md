# Mustang Premium / LE / Boss — switch matrix excerpt

Source: `Mustang_LE_web.pdf`, PDF page 8, crop box 0.06,0.10,0.96,0.54. The rendered crop covers the complete four drive rows and switch columns 1–64 in the Premium/LE/Boss switch matrix.

Drive rows are Q1 GRN-BRN J1-P1, Q2 GRN-RED J1-P3, Q3 GRN-ORG J1-P4, and Q4 GRN-YEL J1-P5. The first row contains start, tournament-start, trough, and orbit/skill switches; the second row contains trough and sling switches; the third row contains pop-bumper, ramp, orbit, bowl, and spinner switches; and the fourth row contains the lower-ramp, turntable, bank, and cabinet/service cells. The matrix prints the switch numbers, location labels, SPI part references, return-wire columns, and the distinction between below-playfield and above-playfield devices.
