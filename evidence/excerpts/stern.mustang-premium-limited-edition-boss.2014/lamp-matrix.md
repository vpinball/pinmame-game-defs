# Mustang Premium / LE / Boss — lamp matrix excerpt

Source: `Mustang_LE_web.pdf`, PDF page 10, crop box 0.06,0.08,0.96,0.54. The rendered crop covers the visible first five lamp rows of the Premium/LE/Boss lamp matrix.

The matrix headers identify eight 18VDC columns on the I/O power-driver board: YEL-BRN J13-P1, YEL-RED J13-P2, YEL-ORG J13-P7, YEL-BLK J13-P9, YEL-GRN J13-P6, YEL-BLU J13-P4, YEL-VIO J13-P3, and YEL-GRY J13-P8. Rows Q33–Q37 are RED-JAN J12-P1, RED-BLK J12-P2, RED-ORG J12-P3, RED-YEL J12-P4, and RED-GRN J12-P5; the visible cells include START BUTTON, MUSTANG/NIGHT inserts, PONY TOP LANE, FORD inserts, JACKPOT, RIGHT ORBIT, MUL TIBALL, DROP TARGET, and return/outlane labels. Every populated cell is marked LED with the printed SPI part 112-5033-08.
