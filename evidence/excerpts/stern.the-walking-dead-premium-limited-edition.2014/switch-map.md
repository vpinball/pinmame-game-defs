# The Walking Dead Premium / LE — switch inventory excerpt

Source: `Walking Dead pinball Manual.pdf`, PDF page 10, crop box 0.07,0.08,0.94,0.62. The crop transcribes the visible lamp/switch inventory rows 1–32 of the Premium/LE service manual.

Rows 1–2 are Start Button and Tournament Start Button; row 3 is 2X Playfield values; row 4 is Shoot Again; rows 5–21 are the Walker, multi-kill, and Horde inserts; rows 22–23 are Left Outlane and Left Return Lane; row 24 is R. Loop Arrow; row 25 is Blood Bath; rows 26–28 are First Aid, Weapons, and Food; rows 29–31 are L. Ramp Walker Kill, L. Loop Walker Kill, and L. Loop Multi-Kill; row 32 is Barn Mode. The table records each board location, connector/pin, wire color, lamp type, physical location (`Cab.` or `PF`), and SPI part number.
