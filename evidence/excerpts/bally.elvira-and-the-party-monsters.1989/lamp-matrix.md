# Bally Elvira and the Party Monsters (1989) — Lamp Wiring Diagram & Matrix

Source: Bally Midway *Elvira and the Party Monsters* Operations and Parts Information Manual
16-2011-101, IPDB machine 782 file `Elvira_and_the_Partymonsters_OCR_searchable.pdf`, PDF page 90,
printed page 2-38. Read from the native 300 dpi render. The same grid is printed again on PDF page 42
(printed 1-36, inside the Lamp Tests text) and on the quick-reference page PDF 117 ("ELVIRA Lamp
Matrix"); all three copies agree cell for cell.

Wiring diagram (top half of the page): columns leave connector `1P7` on pins 1, 2, 3, 4, 6, 7, 8, 9
(`Yel/Brn` Column 1 through `Yel/Gry` Column 8); rows return on `1P6` pins 1, 2, 3, 5, 6, 7, 8, 9
(`Red/Brn` Row 1 through `Red/Gry` Row 8). "Typical Lamp Circuit" shows each lamp in series with a
diode from column to row.
