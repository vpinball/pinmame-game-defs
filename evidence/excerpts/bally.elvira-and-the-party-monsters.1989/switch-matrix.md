# Bally Elvira and the Party Monsters (1989) — Switch Wiring Diagram & Matrix

Source: Bally Midway *Elvira and the Party Monsters* Operations and Parts Information Manual
16-2011-101 (August 1989), IPDB machine 782 file `Elvira_and_the_Partymonsters_OCR_searchable.pdf`,
PDF page 88, printed page 2-36. Read from the native 300 dpi render. The same grid is printed again
on PDF page 45 (printed 1-39, inside the Switch Tests text) and on the unpaginated quick-reference
page PDF 117 ("ELVIRA Switch Matrix"); all three copies agree cell for cell.

Wiring diagram (top half of the page): columns leave connector `1P8` on pins 1, 2, 3, 4, 5, 7, 8, 9
(`Grn/Brn` Column 1 through `Grn/Gry` Column 8); rows return on `1P10` pins 9, 8, 7, 6, 5, 3, 2, 1
(`Wht/Brn` Row 1 through `Wht/Gry` Row 8). "Typical Switch Circuit" shows each switch in series with
a diode from column to row.
