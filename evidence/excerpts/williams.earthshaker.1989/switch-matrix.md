# Earthshaker — Switch-Matrix Table and wiring diagram (printed pages 67-68)

Source: `earthshaker.pdf`. The switch-matrix wiring diagram is printed at the top of PDF page 71
(printed "EARTHSHAKER 67", above the lamp-matrix table), and the Switch-Matrix Table at the bottom
of PDF page 72 (printed "EARTHSHAKER 68", below the lamp wiring diagram). Read from 200 dpi
renders of the native 300 ppi scan. Every cell is transcribed; a cell that prints only its number
is written "(blank)". A circled digit in a cell is the table's "Zone" marker, written "(zone n)".

## Wiring diagram (printed page 67)

Typical Switch Circuit: column drive through the switch and a series diode to the row return.

| Connector pin | Wire | Signal |
| --- | --- | --- |
| 1P8-1 | Grn/Brn | Column 1 |
| 1P8-2 | Grn/Red | Column 2 |
| 1P8-3 | Grn/Orn | Column 3 |
| 1P8-4 | Grn/Yel | Column 4 |
| 1P8-5 | Grn/Blk | Column 5 |
| 1P8-7 | Grn/Blu | Column 6 |
| 1P8-8 | Grn/Vio | Column 7 |
| 1P8-9 | Grn/Gry | Column 8 |
| 1P10-9 | Wht/Brn | Row 1 |
| 1P10-8 | Wht/Red | Row 2 |
| 1P10-7 | Wht/Orn | Row 3 |
| 1P10-6 | Wht/Yel | Row 4 |
| 1P10-5 | Wht/Grn | Row 5 |
| 1P10-3 | Wht/Blu | Row 6 |
| 1P10-2 | Wht/Vio | Row 7 |
| 1P10-1 | Wht/Gry | Row 8 |

The grid numbers each crossing 01-64 down each column: column 1 carries 01-08, column 2 09-16,
and so on to column 8 with 57-64.
