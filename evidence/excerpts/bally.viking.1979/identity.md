# Viking identity correction

Primary curator and independent evidence verifier inspected IPDB 2737, Bally Viking, model 1198, Bally MPU AS-2518-35. The live page states Project Date December 04, 1979 and Date Of Manufacture July, 1980. Pinside machine 527 independently separates designed December 1979 from produced July 1980. Four players.

The prior OPDB-derived knowledge misdescribed the project date as manufacture. Physical release year is 1980 under docs/IDENTITY.md. Keep stable ID bally.viking.1979 and OPDB G57kN-MQ71K; this is a corrected year field and prose, not an identity migration. PinMAME original catalog year 1980 agrees. Clone year 2004 describes conversion firmware, not production.

Retained machine-page payloads: review-artifacts/bally.viking.1979/ipdb-2737.json and pinside-viking.json. IPDB direct manual URL https://www.ipdb.org/files/2737/Bally_1980_Viking_Manual.pdf is linked from verified machine https://www.ipdb.org/machine.cgi?id=2737.
