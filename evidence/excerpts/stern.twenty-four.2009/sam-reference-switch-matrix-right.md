# Shared SAM switch-matrix reference

The Iron Man Vault Edition service manual's page 16 prints the standard SAM switch-matrix rows, columns, wire colors, and CPU/Sound-board connector positions. The 24 definition uses this excerpt only for that shared electrical topology; 24's actual labels and installed contacts come from its own ROM diagnostics and known-working table script.
