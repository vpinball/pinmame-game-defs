# Shared SAM switch-board reference

The Iron Man Vault Edition service manual's page 16 prints the dedicated SAM inputs D-1 through D-24 and DIP positions D-25 through D-30 with their board connections. The 24 definition uses this excerpt only for the shared SAM CPU/Sound-board addressing and connector convention; it does not transfer Iron Man switch names, physical population, or game semantics to 24.
