# Shared SAM output-board reference

The Iron Man Vault Edition service manual's page 20 prints the SAM I/O Power Driver board's Q1 through Q32 output table, including driver designators and control-connector positions. The 24 definition uses this excerpt only for the shared board convention and reconciles 24's installed devices and high-side supplies against its own ROM diagnostic evidence; no Iron Man device label is transferred.
