# Williams Firepower (game 497) — Figure 6, Lamp Matrix

Source: `Williams_1980_Firepower_Instruction_Booklet.pdf` (IPDB 856, Instruction Booklet
16P-497-103, January 1980), PDF page 12, printed page 12. The page is printed sideways; it is
transcribed here in the orientation the grid reads. Transcribed by hand from a native-resolution
render. All sixty-four cells are written down, including the one printed `NOT USED` cell.

Heading, verbatim: `Figure 6. Lamp Matrix`.

Unlike Figure 5, the cells carry no printed lamp number. The lamp number used in this project is
the position `(column - 1) * 8 + row`, which is the numbering the schematic's playfield lamp
wiring diagram prints as bulb numbers 1-49 and 56 (see `playfield-lamp-wiring.md`).
