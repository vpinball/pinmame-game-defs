# Williams Firepower (game 497) — Figure 5, Switch Matrix

Source: `Williams_1980_Firepower_Instruction_Booklet.pdf` (IPDB 856, Instruction Booklet
16P-497-103, January 1980), PDF page 11, printed page 11. The page is printed sideways; it is
transcribed here in the orientation the grid reads. Transcribed by hand from a native-resolution
render. Every one of the sixty-four cells is written down, including the eleven printed `NOT USED`
cells, because an unfitted position is only visible if it is transcribed.

Heading, verbatim: `Figure 5. Switch Matrix`.

Each cell prints a function and, in its lower right corner, the switch number. The number is the
position `(column - 1) * 8 + row`.
