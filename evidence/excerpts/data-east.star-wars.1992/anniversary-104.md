The following factual paraphrase covers the complete V1.04 change list, headed
December 19, 2012 (the IPDB download label gives the later release date,
December 24). These dates do not change the physical machine's 1992 release.

| Feature | V1.04 change described by Stern |
| --- | --- |
| Ball save | Freeze feature added, with a ten-second timer |
| Force collection | Ramp stops collecting the Force award |
| Ramp progression | Smaller climbing bonus |
| Force relight | Every fifth ramp shot |
| Ramp extra ball | Counting logic revised |
| STAR WARS letters | No automatic starting S each ball |
| Sarlacc | Bumper-built value increased |
| Jabba scoop | Pays Sarlacc value plus the lit Jabba award |
| Relaunch relight | Uses elapsed time of the current ball |
| Left orbit relight | One completed drop bank can relight it when required |
| Force extra ball | Higher award probability |
| AT-AT mode | Fewer required bumper hits |
| Dark Side | More required shots |
| Shoot The Death Star | Active state survives a drain |
| Tri-Ball | Higher initial jackpot |
| Bonus | Larger end-ball awards and maximum |
| High scores | Lower default scores |
| Combos | Higher combo and super-combo awards |
| Combo audio | Additional sound calls |
| Skill-shot audio | Stereo pan synchronized to display |
| Cave shot | Added voice calls |
| Super Laser Kick | Force award gains sound and video |
| Orbit audits | Left/right counters corrected |
| Force audit | Counter corrected |

This is rules/firmware evidence. It does not supply EPROM installation or DMD
socket instructions and cannot establish physical compatibility for the other
ten catalog sets. The record therefore keeps variant_differences missing.
