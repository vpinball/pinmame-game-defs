# Bally Indianapolis 500 (1995) — Power driver board connectors J130-J138 (printed 3-26)

Source: Midway Manufacturing Company *Indianapolis 500* operations manual (152-page image-only scan,
IPDB machine 2853 file `indy500manualfull.pdf`; the untouched download is retained as
`indy500manualfull.original-scan.pdf`), PDF page 144, printed page 3-26, both columns of the power
driver board connector list. Read from the native 300 dpi render.

Printing notes: the handbook's lamp matrix prints the rows on `J133-1..J133-9` and the columns on
`J137-1..J137-6`, `J138-7`, `J138-9`, while this list marks J133 and J137 `Not Used` and puts the rows on
J135 and the columns on J138 (J135-3 and J138-8 are keys). The wire colours agree between the two;
this list prints no transistors.
