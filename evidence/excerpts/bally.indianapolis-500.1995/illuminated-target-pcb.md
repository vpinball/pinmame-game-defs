# Bally Indianapolis 500 (1995) — A-19823 4-LED Illuminated Target PCB Assembly

Source: Midway Manufacturing Company *Indianapolis 500* operations manual (152-page image-only scan,
IPDB machine 2853 file `indy500manualfull.pdf`; the untouched download is retained as
`indy500manualfull.original-scan.pdf`), PDF page 87, printed page 2-13, upper half. Read from the
native 300 dpi render.

Title as printed: **A-19823 / 4-LED Illuminated Target PCB Assembly**.

| Part Number | Designator | Description |
| --- | --- | --- |
| 5010-09036-00 | R2 - R5 | Resistor, 100Ω, 1/4w, 5% |
| 5010-08930-00 | R1 | Resistor, 470Ω, 1/2w, 5% |
| 5490-13341-00 | OPTO1 | IC Opto Inter w/Tab 10MA. |
| 5671-14509-00 | LED1 - LED4 | LED Red Clear |
| 5791-12622-10 | J1 | Connector, 10-pin Header R/A Lck. |
| 5070-09054-00 | D1 - D5 | Diode 1N4004, 1.0A. |
| 03-9402 | LED1 - LED4 | Spacer .38" |

Board drawing: the four LEDs sit in a 2x2 group at the top of the upright board, printed `LED3`
(top left), `LED2` (top right), `LED4` (bottom left) and `LED1` (bottom right); `OPTO1` (pins printed
C, K, E, A) sits below them, then diodes `D5`-`D1` and `R1`, then connector `J1` (pins 10 to 1).

The handbook prints this part number for switches 56-58 (Left/Center/Right Lightup, shaded opto)
and for lamps 71-78 and 81-84 (Lightup 1-3, Lower Right/Upper Right/Upper Left/Lower Left).
