# Bally Indianapolis 500 (1995) — Flasher Wiring

Source: Midway Manufacturing Company *Indianapolis 500* operations manual (152-page image-only scan,
IPDB machine 2853 file `indy500manualfull.pdf`; the untouched download is retained as
`indy500manualfull.original-scan.pdf`), PDF page 125, printed page 3-7, drawing titled
**FLASHER WIRING**. Read from the native 300 dpi render.

Common supply as printed: `J107 6 Red-White +20VDC` to all flasher lamps (block label
`PLAYFIELD FLASHERS`; left block label `POWER DRIVER BOARD`).

| Connector pin | Printed wire | Printed lamp box |

| J122-1 | Blue-Brown | CENTER JET Sol 25 |
| J122-2 | Blue-Red | RIGHT SIDE Sol 26 |
| J122-3 | Blue-Orange | LEFT SIDE Sol 27 |
| J122-4 | Blue-Yellow | RIGHT RAMP ENTER Sol 28 |
| J126-3 | Black-Orange | ORANGE CAR Sol 19 |
| J126-4 | Black-Yellow | YELLOW CAR Sol 20 |
| J126-5 | Blue-Green | BLUE CAR Sol 21 |
| J126-6 | Blue-Black | GREEN CAR Sol 22 |
| J126-7 | Blue-Violet | LEFT JET Sol 23 |

| J127-9 | Blue-Gray | TOP RIGHT CORNER Sol 16 |

Printing notes, preserved literally: the three J127 wires on this drawing (`Black-Yellow`,
`Blue-Gray`, `Blue-Gray`) differ from the handbook solenoid table (`Brn-Blu`, `Brn-Vio`, `Brn-Gry`)
and from the power driver board connector list on printed 3-25 (`Brown-Blue`, `Brown-Violet`,
`Brown-Gray`); the drawing repeats `Blue-Gray` for two pins and re-uses the J126-4/J126-8 colours.
Each lamp box is drawn as one lamp; the drawing prints no bulb count.
