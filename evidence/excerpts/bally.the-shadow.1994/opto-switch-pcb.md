# Bally The Shadow (1994) — A-14534 Opto Switch PCB Assembly

Source: *The Shadow* Operations Manual 16-50032-101, November 1994 (`Manual_Bally_1994_The_Shadow.pdf`, IPDB 2528), PDF page 107, printed page 2-12. Read from the native 300 dpi
render (parts table only; the small board drawing was not transcribed). This assembly shares printed
page 2-12 with A-18159-1 (10-Opto Switch PCB & Bracket Assembly). It is not one of the pages explicitly
assigned by part number, but the task asked for a search of "A-14534" across the manual, and this
heading is the primary hit for that part number, so it is transcribed here for completeness. Note that
the *switch* part number `A-14534` used elsewhere in this manual (e.g. Switch Locations items 37/38,
"Mini Limit Left"/"Mini Limit Right") refers to this same board assembly, not a different part.

| Part Number | Designator | Description |
| --- | --- | --- |
| 5070-09054-00 | D1 | Diode 1N4004 1.0A. |
| 5010-08930-00 | R1 | Resistor, 470Ω, 1/2w, 5% |
| 5490-12451-00 | - | Opto Inter Ig. 10MA |

Printing notes: the last row's description is printed literally "Opto Inter Ig. 10MA" (an abbreviated/
truncated form, apparently for "Opto Interrupter, 10MA"); transcribed exactly as printed, including the
capital "I" in "Ig." which reads as a stylized "Interlg." split oddly by the typesetting. No designator
is printed for this last row (the em-dash placeholder is used here for the blank cell, matching the
style of the other tables in this set).
