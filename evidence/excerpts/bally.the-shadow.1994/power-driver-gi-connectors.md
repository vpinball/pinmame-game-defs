# Bally The Shadow (1994) — Power Driver Board G.I. Connectors

Source: *The Shadow* Operations Manual 16-50032-101, November 1994 (`Manual_Bally_1994_The_Shadow.pdf`,
IPDB 2528), PDF page 173, printed page 3-28, the power driver board connector list: the complete
**J120** block (left column) and **J121** block (right column). Read from the native 300 dpi render.

## J120

| Pin | Wire | Function |
| --- | --- | --- |
| J120-1 | | Not Used |
| J120-2 | | Not Used |
| J120-3 | Yellow | Return G.I. to playfield |
| J120-4 | | Key |
| J120-5 | Green | Return G.I. to playfield |
| J120-6 | | Not Used |
| J120-7 | | Not Used |
| J120-8 | | Not Used |
| J120-9 | White-Yellow | 6.8VAC to playfield |
| J120-10 | White-Green | 6.8VAC to playfield |
| J120-11 | | Not Used |

## J121

| Pin | Wire | Function |
| --- | --- | --- |
| J121-1 | Brown | Return G.I. to insert |
| J121-2 | Orange | Return G.I. to insert |
| J121-3 | | Not Used |
| J121-4 | | Key |
| J121-5 | | Not Used |
| J121-6 | Violet | Return G.I. to insert |
| J121-7 | White-Brown | 6.8VAC to insert |
| J121-8 | | Not Used |
| J121-9 | | Not Used |
| J121-10 | White-Green | 6.8VAC to insert |
| J121-11 | White-Violet | 6.8VAC to insert |

Blank wire cells are printed blank (the row names only the pin and its function).

Printing notes: this list labels J120 "to playfield" and J121 "to insert", the reverse of the G.I.
table printed on PDF pages 2, 137 (2-42) and 151, which puts J121 under its Playfield columns with #44
bulbs and J120 under its Backbox columns with #555 bulbs, and names the J121 strings Bottom Playfield,
Top Left Playfield and Top Right Playfield and the J120 strings Insert Bottom and Insert Top. The list
also disagrees with that table on two pins: it prints J121-8 Not Used where the table's string 02
(Top Left Playfield) takes its Wht-Org feed from J121-8, and it prints a White-Green feed at J121-10
where no G.I. table row uses J121-10 (White-Green is string 04's colour, on J120-10).
