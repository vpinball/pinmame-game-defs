# Sega GoldenEye (1996) — Switch Matrix Descriptions with Part Numbers and Locations

Source: Sega Pinball *GoldenEye* operations manual (`Sega_1996_Goldeneye_Manual.pdf`), PDF page 33,
printed page 21 (Section 3, Chapter 2), table **Switch Matrix Descriptions with Part Numbers and
Locations**. Read from the native 300 dpi render.

The page's playfield drawing and its legend boxes (`= Switches located above playfield`, `= Switches
located below playfield`, cabinet and not-used swatches) carry no switch numbers in this scan, so only
the table is transcribed. An asterisk marks switches the page says are located in the cabinet.
