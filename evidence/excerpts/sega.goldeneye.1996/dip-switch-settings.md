# Sega GoldenEye (1996) — CPU DIP Switch Settings, Loc. SW300 CPU/Sound Board

Source: Sega Pinball *GoldenEye* operations manual (`Sega_1996_Goldeneye_Manual.pdf`), PDF page 4,
Find-It-In-Front: Dr. Pinball page ii, block **CPU DIP SWITCH SETTINGS, LOC. SW300 CPU/SOUND BOARD —
GOLDENEYE: CUSTOM FACTORY ADJUSTMENTS BY COUNTRY\***. Read from the native 300 dpi render. Each
country prints a two-row grid of positions 1-8 with a filled dot in either the ON or the OFF row.

Footnote as printed: `*All countries not noted below use the "USA CPU Country Setting"`.

| CPU country setting | ON positions | OFF positions |
| --- | --- | --- |
| USA \* | none | 1, 2, 3, 4, 5, 6, 7, 8 |
| AUSTRIA | 1 | 2, 3, 4, 5, 6, 7, 8 |
| BELGIUM | 2 | 1, 3, 4, 5, 6, 7, 8 |
| CANADA | 1, 2 | 3, 4, 5, 6, 7, 8 |
| ENGLAND | 1, 3 | 2, 4, 5, 6, 7, 8 |
| FRANCE | 2, 3 | 1, 4, 5, 6, 7, 8 |
| GERMANY | 1, 2, 3 | 4, 5, 6, 7, 8 |
| HOLLAND (DUTCH) & NETHERLANDS | 3 | 1, 2, 4, 5, 6, 7, 8 |
| ITALY | 4 | 1, 2, 3, 5, 6, 7, 8 |
| JAPAN | 1, 4 | 2, 3, 5, 6, 7, 8 |
| NORWAY | 2, 4 | 1, 3, 5, 6, 7, 8 |
| SWEDEN | 1, 2, 4 | 3, 5, 6, 7, 8 |
| SWITZERLAND | 3, 4 | 1, 2, 5, 6, 7, 8 |

The JAPAN grid's position header is printed `1 2 3 4 5 6 7 2`; its last column is position 8. No
printed setting turns positions 5-8 ON.
