# Sega GoldenEye (1996) — Quick Reference Fuse Chart

Source: Sega Pinball *GoldenEye* operations manual (`Sega_1996_Goldeneye_Manual.pdf`), PDF page 3,
Find-It-In-Front: Dr. Pinball page i, **NEW BACKBOX LAYOUT, FUSE & RELAY LOCATIONS**, table **QUICK
REFERENCE FUSE CHART**. Read from the native 300 dpi render. The backbox layout above the chart shows
the I/O Power Driver Board carrying the `G.I. Relay`.
