# Sega GoldenEye (1996) — Coils Detailed Chart Table

Source: Sega Pinball *GoldenEye* operations manual (`Sega_1996_Goldeneye_Manual.pdf`), PDF page 36,
printed page 24 (Section 3, Chapter 2), table **COILS DETAILED CHART TABLE** (coils #1-#24). Read from
the native 300 dpi render. The Find-It-In-Front page iv (PDF page 6) reprints the same table; the
flash lamps #25-#32 continue on page v (see `flash-lamps-chart.md`). Every row prints the driver
output board `I/O Pwr. Drvr.` (row 16 prints `I/O Pwr. Drvr.` with a broken glyph).
