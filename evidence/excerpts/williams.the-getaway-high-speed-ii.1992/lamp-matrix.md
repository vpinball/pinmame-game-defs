Every address 11-88 is populated; this manual prints no "Not Used" lamp position (unlike the switch
matrix). Labels here are used as printed except where the Lamp Locations parts list (`lamp-
locations.md`) gives a fuller description for the same address (e.g. matrix cell "Getaway" at 26
matches parts-list "Getaway #555" exactly; both sources agree throughout, so no typo correction was
needed for this table, unlike several other curated WPC titles).
