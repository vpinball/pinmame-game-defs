# Demolition Man — Switch Locations

Transcribed from `Williams_1994_Demolition_Man_Operations_Manual_English_OCR_searchable.pdf`, PDF page 101,
printed page `DEMOLITION MAN 2-45`, the `SWITCH LOCATIONS` parts list (`Item`, `Switch No.`, `Where Used`) and the
numbered-balloon playfield drawing beside it. Read from the rendered page (308 dpi 1-bit scan), not from the OCR text.
The cropped image next to this file is the whole page content (title, both tables, drawing and page number).

The list is printed in two blocks: the main list (items `F1` to `F8` then `11` to `78`) down the left of the page, and a second short list
(items `81` to `88`, under its own repeated header `Item  Switch No.  Where Used`) at the lower right under the drawing. Both are transcribed below.
Some items print more than one part number on consecutive lines (a cabinet part, a button and a trigger; an LED and a transistor; a count and
a score switch). Each printed line is one row below; the continuation lines have an empty `Item` and an empty `Where Used`, because the page
prints `Where Used` once, level with the first part line of the item. Blank cells are printed blank.

The page's `Switch No.` column is a Williams part-number column, not a matrix address: the item number is the switch number (as in the `SWITCHES` matrix on PDF page 100).

## Notes on printed values

- Item 75 prints `Not Used` in the `Switch No.` column with an empty `Where Used` cell. Items 37 and 68 print an empty `Switch No.` cell and `Not Used` in `Where Used`. Item 28 prints a part number (`5467-12693-19`) and `Not Used` in `Where Used`. Items F5 and F6 print `Not Used` in `Switch No.` and a normal `Where Used` text.
- The `SWITCHES` matrix on PDF page 100 prints cell 75 as `Elevator Ramp` (unshaded); this list prints item 75 as `Not Used`. The reprint of the matrix on PDF page 106 prints cell 75 as `Not Used`.
- Part numbers are transcribed literally, including the visibly inconsistent ones: item 46 prints `55647-12693-36` (five-digit prefix; the other `5647-12693-nn` rows have four), item 48 prints `5467-12693-19` while the similar items 47 and 55 print `5647-12693-11` and `5647-12693-19`, item 38 prints `A-8017-6` while items 56 and 78 print `A-18017-6`, and items 15 to 18, 28 and 63 to 65 print `5467-12693-19`.
