# X-Men switch matrix

Source: `XMenManual_042214-high-resolution.pdf`, PDF page 56, printed page 4.

The page is the complete `SWITCH MATRIX GRID [#1 - #64]`. It identifies the four drive columns Q1-Q4, the matrix return wires, the switch numbers, labels, and part numbers. The same page also prints the dedicated D-1 through D-32 cabinet switch block and the eight CPU/sound-board DIP positions. The retained crop is the complete table rather than a partial row so that every matrix address used by the definition can be checked against the manual.

The grid's representative load-bearing entries include the two-bank targets, trough switches 18-22, shooter lane 23, outlanes 24/29, center lock positions 39-40, Nightcrawler and Iceman positions 34/35/50/51/56, Wolverine head 54, and the flipper/coin-door dedicated-switch conventions.
