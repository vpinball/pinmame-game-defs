# X-Men lamp matrix

Source: `XMenManual_042214-high-resolution.pdf`, PDF page 58, printed page 6.

The page is the complete `LAMP MATRIX GRID [#1 - #80]`. It names the LED board at each populated address, including character inserts, bumpers, ramps, locks, Wolverine/Magneto/Iceman inserts, and the right-bank targets. The blank cells are retained as blank/unused matrix positions rather than being assigned invented devices.

The full grid is visible in the crop, including the address rows 1-16, 17-32, 33-48, 49-64, and 65-80. This is the manual authority for lamp naming and matrix address order.
