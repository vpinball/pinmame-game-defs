# Indiana Jones — Lamp Matrix / Lamp Locations

Transcribed from `Indiana_Jones_OPS.pdf`, PDF pages 112-113, printed pages 2-48 (Lamp Matrix) and
2-49 (Lamp Locations). Read from the rendered pages, not the OCR text stream, which is scrambled on
this scan. Both pages carry the same address-to-label mapping and are transcribed together as one
table; unlike other machines in this project, neither page prints a bulb-part or assembly column for
individual lamps, so no per-address part data is available from this manual for these addresses.

All 64 matrix positions 11-88 are populated (no "Not Used" lamp on this machine). Every lamp is a
single #555 bulb except 48 and 68 (#44) — no printed `(2)` quantity marker appears anywhere on
either page.
