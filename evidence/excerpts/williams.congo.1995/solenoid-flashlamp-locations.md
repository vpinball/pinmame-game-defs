Notes:

- Item 03's printed bulb number "24-8549" matches none of the four codes defined in this page's own legend (24-6549/#44, 24-8704/#89, 24-8768/#555, 24-8802/#906). The Solenoid/Flasher Table page (evidence/excerpts/williams.congo.1995/solenoid-flasher-table.md) independently states GI address 03 ("Playfield Bottom") uses bulb type "#44" directly (not a legend code), which is `24-6549`. Treated as a manual printing error on this page; "#44" from the cross-referenced table is used as the definition's bulb-type fact.
- Item 33's description on this page is "Upper Left Post" and item 34's is "Mystery Eject" -- neither is a flipper, confirming the note on the Solenoid/Flasher Table excerpt that public addresses 33/34 (which sit in the printed "Upr. Rt." Fliptronic circuit slot) are ordinary coils, not an upper-right flipper.
- Assembly numbers for the "Playfield" and "Backbox" bulb rows of a shared flasher circuit (17, 20, 21, 27, 28) are each printed as two lines on this page (one per bulb); both are transcribed above.
- This page's items 15/16 ("Gorilla Right" / "Gorilla Left") agree with the Solenoid/Flasher Table's printed page 111 order, but two other printed copies of that same table (PDF pages 2 and 118) read the opposite (15 "Gorilla Left" / 16 "Gorilla Right"), and the retained known-working script's own object manipulation agrees with the pages-2/118 reading rather than this page -- see the resolution note in evidence/excerpts/williams.congo.1995/solenoid-flasher-table.md. The curated definition uses solenoid 15 = Gorilla Left, solenoid 16 = Gorilla Right.
