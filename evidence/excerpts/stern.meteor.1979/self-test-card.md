## Uncertain readings
- "BUTTON" in "SELF TEST BUTTON LOCATED INSIDE OF COIN DOOR" is partially hidden by a paper tear; read as BUTTON.
- Item 4 description: printed "(Solenoid driver transistor "Q" number displayed as solenoid is pulsed." with no closing parenthesis visible.
- Switch 12's name wraps: "Bumper (Upper / Right)"; checked at.
- Row "20 thru 29" and the leader: read "20 thru 29" with the "9" overlapping a fold; best reading 29.
- Solenoid "6 thru 11": printed with the "11" in the same typewriter font as "1" resembling "l" ("6 thru 11 ."). Best reading 11.
