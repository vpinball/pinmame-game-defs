# Avatar Pro/LE backbox board layout

Source: Avatar-Manual.pdf, PDF page 38, Backbox Wiring.

The board layout identifies the SAM CPU/sound PCB, the I/O Power Driver PCB 520-5249-00, the J13 lamp columns, J12 lamp returns, J9/J8 high-current solenoids, J7 low-current solenoids, J6 flash lamps, and the dedicated switch connectors J1-J3. It also shows the 128 x 32 dot-matrix display PCB and its cabinet connections.
