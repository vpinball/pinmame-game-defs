# Batman: The Dark Knight Scarecrow crane type 1

Source: Batman_TDK_Manual.pdf, PDF page 163 (printed Section 4, Chapter 2, page 85), Scarecrow crane assembly section.

The manual says the game has two crane assembly types and that the installed type must be identified before ordering parts. Type 1 has a round hub hole and a tear-drop-shaped motor shaft. It explicitly says not to move or pull the crane by hand; the crane must be moved with the Scarecrow motor test through the service menu. The motor mount torque specification is 80-85 in-lb.
