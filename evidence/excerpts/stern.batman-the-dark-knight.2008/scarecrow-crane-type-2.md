# Batman: The Dark Knight Scarecrow crane type 2

Source: Batman_TDK_Manual.pdf, PDF page 170 (printed Section 4, Chapter 2, page 91), Scarecrow crane assembly section.

The manual distinguishes Type 2 by its square hub hole and square-shaped motor shaft, and contrasts it with the round-hub Type 1 assembly. The following pages break down each type separately, so a recreation must use the installed assembly rather than assuming that all machines share one crane geometry.
