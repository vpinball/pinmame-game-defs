# Batman: The Dark Knight Pro lamp matrix

Source: Batman_TDK_Manual.pdf, PDF page 10, lamp matrix grid [#1-#80].

The manual grid maps lamp rows 01-04 to the named playfield lamps and their wiring, including Ground Joker, Start Button, Batmobile, Tournament, Scarecrow, shooter, lanes, Joker, Bruce Wayne, Commissioner Gordon, Rachel, Harvey Dent, Alfred, Batman and the crane-position indicators. It is the physical lamp-name evidence for the Pro lamp matrix.
