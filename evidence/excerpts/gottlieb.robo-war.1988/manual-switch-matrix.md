## Drawing conventions as printed

- The matrix is drawn with eight horizontal strobe lines (left connector A1J6 pins 1-8) and eight vertical return columns that end at the bottom in eight horizontal return lines (A1J6 pins 10-17). Each switch is labelled `SW <strobe digit><return digit>` (SW 30 sits on the STROBE 3 line in the first return column).
- Every switch is drawn with the same symbol: two short parallel plates (a normally-open contact symbol). No switch is drawn with a slash or closed contact.
- Strobes 3 to 7: each switch has a diode (triangle) on the strobe side with a numbered diode-board pin (1-8) printed beside it and, below it, a boxed wire code at the switch output. Pin numbers run 1-8 left to right along each strobe line.
- Strobes 0, 1, 2: the switches are drawn only as bare `SW xx` contacts, with no diode, description, wire box or connector.
- Labels `A9 P3/J3`, `A9 P4/J4`, `A9 P5/J5`, `A9 P6/J6` with a pin number are printed beside some switches in strobes 4-7 (see table).
